# CoTeach 已确认样稿风格的系统化实现

日期：2026-10-02。目标是让真实资料经生产生成入口获得第 19 页新样稿的视觉语言：浅底、明确主体、少量真实关系线、贴近对象的短说明，以及单独突出的关键条件。手工样稿是设计参考，模型输入不含其场景 JSON 或元素坐标。

## 已实现的规则

- 模型负责教学对象、内容和真实关系，程序负责字体测量、图标、坐标和连线路由。页标题 32、核心标签 24、说明 20、必要图注至少 18；每页比较至多三个确定性构图。
- 短线性流程优先采用原生语义图标与同轴箭头。说明的空间归属不产生教学箭头；五环节完整保留四条顺序边。
- 四对象的长标签流程、简单分支及明确反馈采用实测网格。回边与成功出口分别路由，边只来自实际采用的图合同；显式反馈图不会被补成首尾循环。
- 支架状态使用同款可编辑学习者及支持对象；定性图不产生百分比、刻度或固定发展阶段。实际对象身份参与构图评分，不能仅靠文字框面积获得更高分。
- 宽支持面板中的两个命名属性可并排显示；窄面板保持两组信息的阅读顺序。连续说明可共享原生文字框，全部文字与来源映射保留，透明播放区域不能代替事实。
- 同一行的说明面板共用实测最高栏的顶边、底边和宽度，文字仍从统一内边距开始，不按各栏字数分别收缩背景。先编译主图，再定位说明，因此模型返回反序构件也保持同样的邻近与对齐；教师锁定或修改过的构件不参与自动等高。
- 容量不足时只执行一次有界重规划：将完整注释归入对应对象的说明区，或给完整图留一页并将既有条件移至一个续页。不能缩小字体、截断事实或拆掉真实拓扑。
- 教材图片与完整观察图例可单独成页，既有补充解释接在下一页。没有可靠像素定位的观察采用相邻图例，不把概念关系猜成指向图片局部的箭头；原图片字节及全部标注保留。
- 当前页已采用的课堂案例使用独立 `adopted-case:<id>` 来源，与教材原文证据分开。仅完整且唯一对应原案例的观察可以补全归属；数字、否定、条件、比较列及来源页仍严格核对，不给案例伪造教材引用。
- 重排注释时保留真实对象标签，并按原图对象顺序组织说明。支持面板贴近已测量的主图，不能让搭支架的说明误归于独立探索。
- 只有来源责任完整、各页来源区间互不重叠且没有页间指代时，才允许交换完整页面恢复原教学顺序。纯来源校验仍严格拒绝交错、共享、未知或遗漏责任。
- 原生图形内的完整文字进入独立讲稿提示及跨页可见证据；完整文字可定位唯一可见图形。历史 ID、区域定位、教师修改保护和已完成检查点保持原合同。
- PPTX 曲线按完整端点和控制点计算非退化路径视口，保留全局位置、箭头和线型。条件标签预留字体替换余量，仍以 18 号字体重新实测，不靠缩字获得空间。

协议仍为 `schemaVersion: 1` / `teaching-visual-v2`，规划版本为 `teaching-visual-planning-v4`，编译器为 v5、主题为 v3，讲稿版本为 `section-continuous-narration-v34-native-shape-evidence`。尚未完成的视觉阶段指纹包含规划、编译器及主题版本；已有课程不会因升级自动重写。

首批 8 次保留在 `.openpbl-runtime/approved-visuals/model-20261002-v1`。仅 3 次采用模型图解，其余包括来源回退和完整原文回退，存在窄文字块、箭头与条件拥挤及导出裁切。该批没有达到目标风格，不能用“生成完成”作为美观通过。

完整原第 19 页的下一次响应保留在 `model-19-20261002-v2`。事实来源可核对，但最初容量不足；未经修改的原始响应经新的有界重排，在 `replay-19-20261002-v4` 中得到两页原生图解。实际播放器和 LibreOffice 已查看，五图标、四箭头及原页六条展示责任完整。说明卡仍较手工参考密，保留这项视觉反馈。

第二批 5 次保留在 `model-refinement-20261002-v2`，覆盖完整原第 19 页、支架状态、英文长标签、条件分支及真实反馈。最初 3 次采用新图解；第 19 页因模型倒置教学顺序保留原稿，长英文因容量问题回退。所有首稿、回退及诊断均保留。

中间重放 `replay-refinement-20261002-v3` 的实际 Office 检查还发现回路曲线的零宽/零高视口导致走形、分支条件标签换行，以及第 19 页局部说明标签归属不清。这些失败保留，导出修复对原失败数据的隔离实开证据见 `export-curve-fix-20261002-v1/curve-review.json`。另有一次重放误选未生成的三个 fixture，缺响应错误保存在 v4；工具已改为默认只取原模型批次实际尝试的案例。
