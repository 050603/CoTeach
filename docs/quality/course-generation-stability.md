# 课程资源生成稳定性：请求语义与运行预算

## 请求与恢复约束

- 配置语义：省略/`baseline` 保留供应商默认值，`none` 转换成显式 disabled。恢复参数不再把空配置标记为 none；与管理端强制关闭要求冲突时明确报错。
- 任务预算：正式生成的规划、教学设计、讲稿、课件、互动、动作和角色七类任务分别分配输出空间，再随输入规模增长。模型容量仅作为截顶上限；显式思考配置保留。预算版本进入生成指纹。
- 超时分类：无活动期限可按现有传输策略恢复；最大执行期限返回 `LLM_EXECUTION_BUDGET_EXCEEDED`、`isRetryable:false`，不重复同一请求；用户取消优先。
- 可观测性：保存每次调用的请求预算与思考设置，以及原有正文/推理字符、首输出时间、完成状态和尝试记录。记录的是调用策略，不是供应商实际执行结果；以协议测试及响应观测交叉验证。
- 缓存身份：恢复时同时核对生成身份、阶段及输入哈希，策略改变后不能复用旧响应，也不能错误继承旧策略的失败次数。

这些约束作用于计算资源和恢复机制，不规定教学步骤、页面段落、例子或互动数量。输出预算是保守估算，不是分词器，也不能保证模型在期限内结束思考；模型返回 length 截断时仍须拒绝，不得交付不完整 JSON。没有增加重试次数或延长 600 秒期限。

## 验证范围

HTTP 级测试覆盖流式 SDK 的关闭/低强度/默认参数与并发隔离；行为测试覆盖动态预算、模型容量截顶、最大期限不重试、空闲恢复、外部取消及缓存身份。
