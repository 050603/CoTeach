# 课程资源生成稳定性：请求语义与运行预算

## 本次故障证据

2026-09-19，3010 实验 `adaptive-narration-final-2026-09-19` 的师范教学方法课程第二页课件两次失败。首个输出分别在约 1.1、2.5 秒到达，随后持续产生 140,957、173,554 个推理字符，正文均为 0；两个请求都在本地 600 秒执行期限结束。证据不支持将此次故障归因于连接无响应。

根因是实验 `--reasoning none` 只检查解析配置为空，没有发送禁用配置。空配置的真实含义是继承供应商默认值。阿里云 DeepSeek V4.1 默认启用高强度思考，需要顶层 `enable_thinking: false` 才能关闭，且不支持 `thinking_budget`。协议依据：[阿里云 DeepSeek API](https://help.aliyun.com/zh/model-studio/deepseek-api)。

同时存在两项放大因素：每次请求直接使用模型的 393,216 token 输出容量；本地最大执行期限被归类为可重试的传输超时，重复执行相同工作。

## 设计修复

- 配置语义：省略/`baseline` 保留供应商默认值，`none` 转换成显式 disabled。恢复参数不再把空配置标记为 none；与管理端强制关闭要求冲突时明确报错。
- 任务预算：正式生成的规划、教学设计、讲稿、课件、互动、动作和角色七类任务分别分配输出空间，再随输入规模增长。模型容量仅作为截顶上限；显式思考配置保留。实验采用共享的保守课件预算。预算版本进入生成指纹。
- 超时分类：无活动期限可按现有传输策略恢复；最大执行期限返回 `LLM_EXECUTION_BUDGET_EXCEEDED`、`isRetryable:false`，不重复同一请求；用户取消优先。
- 可观测性：保存每次调用的请求预算与思考设置，以及原有正文/推理字符、首输出时间、完成状态和尝试记录。记录的是调用策略，不是供应商实际执行结果；以协议测试及响应观测交叉验证。
- 缓存身份：恢复时同时核对生成身份、阶段及输入哈希，策略改变后不能复用旧响应，也不能错误继承旧策略的失败次数。

这些约束作用于计算资源和恢复机制，不规定教学步骤、页面段落、例子或互动数量。输出预算是保守估算，不是分词器，也不能保证模型在期限内结束思考；模型返回 length 截断时仍须拒绝，不得交付不完整 JSON。没有增加重试次数或延长 600 秒期限。

## 验证范围

HTTP 级测试覆盖流式 SDK 的关闭/低强度/默认参数与并发隔离；行为测试覆盖动态预算、模型容量截顶、最大期限不重试、空闲恢复、外部取消及缓存身份。

真实实验使用原先失败的同一课程场景、同一模型和 TTS，另建实验 ID，不覆盖历史结果；重新生成的文本会变化，因此它是端到端复验，不是严格固定输出的性能基准。成功生成不能替代教学、时长和视觉质量评价，实验界面保留这些告警。

## 2026-09-19 实验结果

原失败课程为「中小学人工智能教育的教学理论与方法」。关闭推理复验 `resource-stability-2026-09-19`：教学设计 28.5 秒、两页讲稿约 6.3/6.4 秒、两页课件约 10.8/6.9 秒、测验 7.2 秒；这六次模型调用全部首轮完成，reasoningCharacters 均为 0。PPTX、讲稿、课堂 JSON、音频 ZIP 已生成，3010 下载均 HTTP 200；两页可切换，音频可播放。该样本仍有布局告警，实际音频 255.6 秒相对目标 180 秒偏长，不将其标注为教学质量全面通过。

保留低强度推理的对照 `resource-stability-low-2026-09-19`：教学设计 129.8 秒，两页讲稿约 49.0/91.5 秒，两页课件约 232.9/305.1 秒，均首轮完成；输出存在推理字符，符合启用配置。两组结果说明修复了配置语义和本次失败路径，不构成所有课程的成功率或性能保证。

验证：27 项请求链路/预算/期限测试和 79 项实验室测试通过，实验室类型检查与相关 ESLint 通过。生产构建、实验室构建通过，3000/3010 服务更新且健康检查成功。全库 `pnpm typecheck` 仍有既有的三处测试类型错误，位于 `download-course-resources.test.ts:15` 与 `action-service.test.ts:66,83`，本次未修改这些文件。

低强度对照整课最终完成：测验 16.1 秒，实际音频 194.4 秒（目标 180 秒，+8%），六次模型调用均一次完成。仍保留第二页的一处相邻内容区域告警及结尾转练习提示不足，不把技术交付完成等同于所有质量指标合格。3010 批次名称分别为「稳定性根因修复 · 关闭推理」和「稳定性根因修复 · 低强度推理」。
