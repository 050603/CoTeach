# 正式课程生成：学情驱动的教学设计与高思考执行

## 与实验方法的融合

正式系统使用课程既有的学段、学科、学习目标、先备知识、学习需要、熟悉情境、已确认知识点和教学资料。学情通过 `teachingConstraints` 进入大纲、蓝图、分小节教学设计、课件和讲稿；这些信息用于选择讲解深度、术语解释与例子，不是学生端应朗读的画像，也不代表未填写的能力已经掌握。

共享 `TeachingBrief` 保留兼容字段，并增加 `teachingPlan`：页面职责、已有基础、新增认识、理解难点、推理链、自然得出的结论，以及画面/讲稿各自承担的内容。`examples`、`conditions` 可以为空，推理步数按内容需要决定，不要求每页重复完整教学流程。已确认页数和顺序仍由教师批准的大纲决定。

讲稿继续使用听觉优先的共享规则：准确术语配合学生熟悉的表达，明确指代，展开复杂关系；讲稿与 PPT 均不添加普通教学案例的真实性说明。正式幻灯片/互动适配分支现在能收到学情约束，不再在转交基线生成器时丢失。预生成的补缺/进阶分支同样使用班级学情和已确认分支知识边界，保留片段真实时长，不套用整课的最小时长或知识点数量。

节末测验在讲授页完成后生成，以同小节、测验之前的实际语音讲稿作为考查边界。不得把规划目标中出现但没有讲清的内容视作已教；明确跨小节教学单元依赖的测验才可以引用对应已完成内容。缺少讲授依赖时停止该测验，保留已完成页面。

## 教师控制模型思考深度

原有教师端 AI 场景设置继续决定思考模式，资源策略不替换教师设置或偷偷降低档位。任务预算将正文空间与推理余量分开估算，按资源类型、输入规模和思考档位变化，模型能力仅作为容量上限；模型支持的显式思考 token 配置保留。

课程规划和页面请求采用流式传输，执行期限按本次任务输出预算估算，空闲期限单独计算。接收推理或正文会更新活动状态，但不会无限延长总期限。达到本地执行预算属于明确的不可重试失败；不以重复发送相同请求替代容量规划。

可配置参数：

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `OPENPBL_COURSE_MIN_TOKENS_PER_SECOND` | 20 | 用于预算规划的保守吞吐假设，非供应商性能承诺 |
| `OPENPBL_COURSE_STARTUP_ALLOWANCE_MS` | 120000 | 请求启动与非 token 工作的余量 |
| `OPENPBL_COURSE_EXECUTION_MAX_DURATION_MS` | 7200000 | 单次请求独立安全上限，非统一等待时长 |

总期限为“启动余量 + 分配 token 数 / 吞吐假设”，并考虑空闲期限与独立安全上限；已有 `OPENPBL_LLM_STREAM_MAX_DURATION_MS` 仍作为安全上限的兼容配置。未启用新执行策略的调用保留原语义，3010 的显式实验期限不被暗改。高思考不是永不失败的保证；输出截断、格式错误和事实质量仍须分别验证。

## 长任务、恢复与缓存

- 准备/规划、教学设计和页面生成保持后台心跳，持续推理不被误认为作业掉线。
- 页面进度区分正在思考和正在接收正文，只记录活动统计，不向学生或教师展示内部推理正文。
- 排队不消耗请求执行期限或持久化尝试次数；取得模型槽位才记录真正开始的请求。
- 模型、思考配置、输出/执行预算策略及学情变化进入规划与页面缓存身份。
- 页面仍并发生成；测验按讲授依赖另行调度，最终输出维持已确认的大纲顺序。
- 不重写历史成课；新生成或继续任务按当前输入身份验证是否可复用。

## 本轮补齐：实际启用的首稿与审查策略

此前“完整同步”表述不准确：正式端仍有模型版面编辑和独立口语改写回路。本轮以实验当前运行路径为准补齐，未启用实验中保留但不调用的 legacy 整课/逐页语义审查函数。

| 环节 | 正式系统当前实现 |
| --- | --- |
| 知识讲授页 | PPT 与独立讲稿读取同一教学计划、学情和跨页职责，并发生成 |
| 动作 | 共用实验提取的 action-bindings；按稳定语义 ID 或无歧义文本对应关系本地编译，找不到辅助绑定时保留原讲稿并提示 |
| 专用资源 | 白板、视频及互动保留专用动作生成能力；不将其降为只有 speech/spotlight 的普通页 |
| 审查 | 两端共用 course-generation-policy：本地结构/浏览器检查，可作确定性几何调整，无模型版面重写 |
| 讲稿质量 | 首稿提示中完成教学规划与口语自检，合法稿不再自然化重写，风格与时长偏差只提示 |
| 技术失败 | 独立讲稿 JSON/字段/语义引用无效可带具体错误纠正一次；与传输重试共同占用该阶段总共 2 次请求预算，不因纠正重置计数 |
| 恢复 | PPT 与讲稿各自保存；并发任务失败后等待同页在途任务结束，保留成功结果。完成页的布局/风格提示不触发重新生成 |
| 就绪 | 保留确认设计与音频完整性检查；实测时长偏差不再阻止完整资源进入就绪，教师预览仍显示偏差提示 |

### 真实样例暴露的职责和时长问题

首轮首稿策略真实 high 验收用时 492.68 秒、5 次模型调用，无模型润色/版面重做和传输重试。PPT 与讲稿请求启动仅差 12 毫秒；技术断言通过，但人工抽读发现讲授页提前执行了课后测验。因此这不是最终教学质量结论。

v2 独立讲稿明确整课要求仅作背景、当前页职责优先，跨页摘要带页面类型与当前页标记，禁止提前执行别页测验或公布其答案。课件与讲稿的语义编号在基础生成器改写 ID 后通过原始元素类型、几何和内容的唯一精确对应恢复；缺失或歧义时不猜测，不请求模型重做。

另一个根因在预算分配：缺时长的测验被默认成 300 秒，作答时间之外的大部分余量被转为朗读，随后又与讲授页面一起按文字权重重分。样例的一道简单单选因此得到 186 秒/863 字朗读预算。现在缺省时长按题量、题型和难度的阅读推理需求估算，语音只承担引导和解析，额外时间归学生阅读、作答与检查；明确指定总时长仍保留。这是可校准的规划启发式，不是每题固定句数或硬性教学步骤。阶段重分仅调整尚无明确蓝图分项的讲授页，不再混入测验、互动或已确认分项。该样例新预算为 74 秒页面、21 秒朗读、48 秒学生时间、5 秒过渡。

最终真实复验使用新目录 `.openpbl-runtime/formal-technical-policy-v2-2026-09-19`；校验原始输入身份和 high 设置后，仅复用同一案例的共享教学设计与教学页课件，重新计算时长、生成独立讲稿和依赖它的测验。此复验不应被计作从零生成整课的性能测试。


最终 v2 真实 high 复验通过：37.87 秒、3 次真实请求（共享设计/PPT已复用），独立讲稿首稿逐字保留、测验实际 1 题且基于新讲稿、无润色/版面重做/技术重试。教学页仍为目标 70 秒、计划朗读 67 秒；测验计划朗读 21 秒。人工抽读教学稿 361 字/4 段，未再提前执行测验，测验导语与反馈共 168 字。机器报告 local-technical、ready，无警告；这些结果不代表所有未来课程均已验证。此次没有合成 TTS 或图片/视频。语义 ID 恢复另有真实基础生成器转换边界测试，不把本轮复用的旧课件冒充新映射端到端结果。

## 2026-09-19：先统一小节设计，再生成各页内容

本轮修复了“蓝图已有解释与边界，但分小节设计只收到标题和要点”的信息断层。正式生成现在按以下关系工作：蓝图确定小节学习用途、共享案例和页面间的认识进展；分小节设计完整继承蓝图已有解释、机制、例子、边界与页面职责；课件和独立讲稿并发读取同一份设计；节末测验等待实际讲稿完成，以讲授范围限制考查内容，以资料证据、适用条件和概念边界判断答案正误。没有增加模型审查或润色阶段。

`TeachingBlueprintSection` 增加共享教学上下文，记录学习用途、案例事实、固定原句、稳定术语和概念边界。`TeachingBrief` 兼容性增加同一上下文及可选页面学习任务；变式任务分别记录改变条件和保留条件。没有任务的机制解释页可以省略该字段。局部恢复只补缺页，并同时读取同节已完成设计和共享案例，不重新命名或重建案例。

共用准确性策略区分定义、案例安排和辅助判断线索。替换、删除、比较和影响范围可以帮助理解，但不能单独成为定义、充分条件或标准答案；资料原文准确不代表附带推论已获支持；教案没写出依据只表示依据没有写出。相邻页面必须增加新推理、明确条件变化或独立应用。同一案例的关键句、步骤名称和术语保持一致，解释性改写与真实条件变化分别标明。

讲稿首稿按页面职责生成。引入多个陌生概念时，先自然说明用途，再展开案例行动与观察，之后分别命名和解释；变式页第一段只交代改变项、保留项并提出判断，系统用已规划的学生时间在解释前插入思考停顿。课件的变式或独立判断页显示待判断材料、改变项和保留项，不在主画面同时公布全部答案。首稿返回前在同一次调用内检查缺词、重词、同音替换和断裂句，不新增二次润色调用。

测验使用实际讲稿限定已教范围，但不会把讲稿中的简化线索升级为答案规则。迁移或应用目标要求一个没有在讲授中公布答案的新片段；共享案例继续提供术语与边界约束，不作为默认原题材料。蓝图已取消每页固定四至六个要点和至少三个要点的门槛，只保留非空内容、知识映射、页面职责和时长检查。
