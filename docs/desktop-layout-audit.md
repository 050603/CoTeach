# 电脑屏幕适配检查

范围：教师/学生登录注册、课程列表和详情、课程库、课程设置弹窗、学生个人中心、学生填写问卷、教师问卷分析与投屏。另检查教师设置、学生名单/档案/导出弹窗、课堂记录；旧历史开课页补上窄电脑窗口单列布局。

## 修复内容

- 学生课程详情：去除固定最小总宽，章节/任务标题允许换行，窄桌面减少编号、进度区及缩进占用。
- 登录注册：左右栏分配与表单宽度自适应；教师注册采用双列字段；短屏压缩留白，大屏适度增大表单文字。
- 课程列表、导航和弹窗：统一有限流体字号、内容宽度及间距；卡片按可用宽度排列；弹窗正文滚动、操作区可换行。
- 学生个人中心：补齐平台主题路由，避免缺失样式和错误加载课堂状态。
- 问卷：普通数据页取消额外整屏高度；答题纸扩展可用宽度；多选项图表局部滚动；投屏词云使用实际容器尺寸，短屏保留可滚动兜底。

## 可重复的浏览器验证

```bash
node scripts/check-desktop-layout.mjs --assert
```

脚本访问本机已启动的实际 Next.js 页面，在浏览器中拦截全部 `/api/` 请求并提供虚构数据，不创建账号、不提交问卷、不修改真实课程。它使用本机 JWT 密钥为虚构身份通过页面入口检查，密钥及 cookie 不写入报告。默认读取 `deploy/secrets/jwt_secret.txt`，也可通过 `LAYOUT_JWT_SECRET_FILE` 指定测试实例的密钥文件；`LAYOUT_BASE_URL` 仅允许本机地址。

覆盖 8 种视口，包括常见笔记本、1080p、1440p、4K 和浏览器缩放后的低高度窗口。检查页面/主要容器横向溢出、词云画布裁切、柱图最小宽度、弹窗边界、平台主题以及浏览器脚本异常。截图和 JSON 报告写入独立的系统临时目录，终端显示其路径。

`--source-css` 可在构建前注入当前源样式检查，但不能验证尚未构建的组件逻辑；交付前应在生产构建完成后不带此选项重新验证。`LAYOUT_SCENARIOS` 可以用逗号分隔场景名缩小复测范围。

这些检查针对 Chromium 的电脑视口及虚构长文本/多选项数据；没有进行手机适配，也不能替代真实课堂全流程、所有历史数据或其他浏览器的验收。旧历史开课页本次仅做源码审查与构建检查，未使用真实历史课堂资料运行回放。

## 本次验证结果（2026-09-11）

- 生产构建后复测 21 个页面/交互场景 × 8 种视口，共 168 项，全部通过上述断言，未捕获浏览器脚本异常。
- 视口：1024×768、1280×720、1366×768、1440×900、1920×1080、2560×1440、3840×2160、1024×576。最后一项用于模拟缩放后较小的可用 CSS 视口，不代表真实浏览器缩放操作测试。
- 人工抽查了注册表单、课程详情、个人中心、短屏弹窗、答题纸、分析图表和投屏词云截图。多选项图表保留局部滚动；普通长页面允许纵向滚动，不强行压缩到一屏。
- 相关 Vitest 测试、修改文件 ESLint、差异空白检查和 `pnpm build` 通过。已重启本机 `openpbl.service`，3000 端口存活检查返回 `alive`。
