# 2026-09-14 冻结 PPT 首遍实验结果

完成 216 个条件记录：24 页 × 3 次 × 3 条件。其中固定提交基线与空间预算组各实际尝试 72 次；非视觉模型的 72 个草图条件明确不可用，没有发送伪装成视觉实验的纯文本调用。144 个实际尝试均有独立截图或无稿失败记录；复核者为 Codex，不等于教师签字。

**空间预算组尚未达到 95% 页面布局通过、关键教学内容全部保留的目标。** 这是冻结版本的实测结果；后续字体、公式、图表和阶段时间提示修复没有回填到本实验。

首稿指标只用第一次模型响应，进行必需的默认值解析和公式编译；不把旧链路修正后的页面算成首稿。布局采用双方一致的严格可见容器边界口径，少量末行越过背景也判未通过；不是每个失败都有严重遮挡。连线穿过标签、白字落在白底、公式裁切和图表压扁则在逐页记录中具体列出。

预算组的 3 个无稿样本均为请求超时，不能当作已观察到的布局缺陷。只看实际出稿，布局通过为 44/69（63.8%），关键内容完整为 64/69（92.8%），仍未达到目标。知识内容判定依据屏幕可见信息，DSL 中有文字但屏幕被裁切或遮挡不算保留。

旧链路最终 24 页和预算组最终 69 页均另做实际播放器测量，其中规则无警告分别为 14/24、18/69。规则结果仅是诊断，不是截图验收；没有另对旧链路最终 24 页声称独立视觉质量通过率。固定提交基线为 `843847af93106f9b6ac64f10154fb056d7141303`，不包含会话开始时工作区已有的“纠正一次后接受草稿”未提交修改，因此不代表当时工作区或线上全部行为，不能用该组的拒绝交付数量夸大改进。

## 前置开销、构图与导出

空间准备及程序草图生成的记录中位数为 2.799 秒、P95 为 3.233 秒，包含浏览器服务队列和字体加载。相同样本的准备结果被缓存复用并记录在多个条件中，不能把这些字段相加当作独立计算总量；纯容量测量的先导计时不替代该端到端开销。

八类构图是**输入覆盖**，没有据此声称输出多样性达标。截图中确实出现横向/纵向流程、能量分类树、食物网节点、叶片标注、原生表格和柱图；大量页面仍采用两列或“上两块、下一块”的文字卡片。预算组 69 个最终页中，39 页含原生连线、4 页含图表、4 页含表格、2 页含公式；这些只是元素使用计数，不是设计质量分数。

[导出兼容记录](export-compatibility.json)仅覆盖 `01-budget-1`、`01-budget-2`、`02-budget-2` 三页：ZIP/XML、22 个元素几何、文字、两份 OMML 公式及一个原生图表数据保留，LibreOffice 可以打开。浏览器与 LibreOffice 仍有公式裁切、图表绘图区和换行差异；未验证全部页面、表格、动画、媒体或 Microsoft PowerPoint，也未宣称像素一致。

## 视觉模型与实验边界

本轮生产路由模型 `deepseek:deepseek-v4-flash` 的配置视觉能力为 false，草图条件不可用。另做一次明确选择的 `deepseek:deepseek-v4-flash-vision-exp` 协议探测，发送程序生成的 PNG，关闭 SDK 和外层重试；338 毫秒返回 `Model not exist.`。虽然配置标记支持视觉，实际模型不可用，不能完成第三组。该探测没有改生产路由，也不计入本轮 233 次已保存逻辑请求。见 [探测记录](vision-probe.json)与[输入图](vision-probe.png)。

实验中途运行环境停止，使用原冻结 bundle 恢复，原结果保留。[恢复依据](resume-evidence.json)记录原 bundle、恢复副本及 baseline 哈希；仅修改实验指纹读取和跳过重新编译 baseline，模型和材料校验仍生效。原始系统提示哈希与恢复前记录一致。中断时未落盘的在途请求可能已发送到供应商，其完成或计费无法确认；逻辑调用数还不包含网络边界内部重试，因此不等于账单总请求数。

尾段与同一模型的另 6 次动作调用、共享主机生产构建并行，供应商负载未隔离。耗时是本轮观察值，不是专用环境性能；不可直接宣称统计显著的性能优势。视觉计划使用 fallback 加固定构图，不评价完整课程规划模型的构图选择。第 24 个材料把 Python 函数写成单行文字，部分页面照录；本轮材料保留不等于代码可执行性验证。
