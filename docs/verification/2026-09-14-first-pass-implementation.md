# 首遍课程生成实现与验收（2026-09-14）

## 已接通的运行链路

新课程先生成课程视觉计划，再计算区域容量、关系图候选布局和程序绘制的空间草图；容量不足时前置拆页。成稿仍输出当前可编辑 OpenMAIC DSL，模型决定最终坐标。文字、富文本、公式和表格使用播放器同源字体/CSS 的浏览器度量；缺少 Chromium 或字体时明确失败。

视觉模型收到 PNG 草图和结构化预算；非视觉模型只接收同一预算，不自动切换模型。旧准备大纲及成功场景检查点原样复用，不重新拆页或因质量意见回炉。结构无法解析时保留其他成功页面并明确失败。

图片和封面不再触发视觉审核或反馈重生；已生成资源的下载恢复不重新请求图片。讲稿先获得锁定音色的时长、段落与发音量预算；视频请求在此之前锁定供应商及可生成的时长，从页面预算中扣除。互动、等待与过渡时间也先预留，反馈纳入讲解时间而不重复扣除。按照用户最新要求，仅知识讲授阶段的总时长采用 ±10% 验收；程序结合大纲原有份额与必需教学内容的预计发音量重新分配讲稿份额，阶段总时长及已预留时间守恒，页与段均为可调整的参考预算。音频通常每段只合成一次。请求边界只对明确网络故障最多重试两次，并传递 `Retry-After`；页面、作业和 SDK 不叠加重试。7 个图片与 6 个视频适配器共用 HTTP 边界；视频轮询失败仅请求原任务，耗尽或轮询超时不重新提交。无效响应结构及已耗尽的请求保留不可重试标记，增加页面上下文也不会恢复重试资格。

预览 GET、生成完成和资源更新不自动入队辅助审核；页面度量只由教师主动启动。未检查明确显示“未检查”，教师可直接确认发布，权限、版本、结构引用及资源完整性校验继续执行。

## 工程验证

- 81 个受影响测试文件、510 项测试通过，覆盖空间容量/拆页守恒、真实参数传递、无质量返工、故障重试上限、同资源下载、TTS 校准隔离和场景检查点恢复。
- 类型检查及 109 个修改或新增文件 ESLint 通过。公式首屏渲染修复的 8 项回归包含在上述测试中；renderer 子包另外 3 项测试、类型检查和构建通过。
- 生产页面的 Chromium 浏览器测试 2 项通过：无辅助报告直接确认发布，以及手动检查页面后确认发布。接口数据使用隔离测试夹具，真实应用页面、渲染器与按钮交互参与验证，不创建或发布教师实际课程。
- 24 个固定样本全部完成真实浏览器前置空间计算：独立空间计算冒烟冷启动约 1.18 秒，热调用每页约 18–38 毫秒。冻结生成实验还计入草图绘制、字体加载与队列，前置处理的中位数约 2.80 秒、P95 约 3.23 秒；两者统计范围不同，均不是独占环境性能基准。
- 真实 Chromium 与 ELK 集成输入三块区域、两条顺序关系，输出一页、两条连线路径，区域均满足容量，总时长保持 91 秒。
- 3 页真实浏览器调用现有 PPTX 导出器：ZIP/XML 可解析，22 个主要元素坐标尺寸误差低于 0.02px，12 个文字框、1 个原生图表、2 个可编辑公式保留。LibreOffice 均可打开。图表绘图区、文字换行有差异，未验证所有样本或声明像素一致。

同一冻结公式 DSL 的独立延迟字体对照：旧播放器在字体完成加载后仍使用过时缩放，公式实际宽 431.53px，超出 390px 容器；应用与渲染器包同步等待字体并响应尺寸变化后，公式完整容纳于原 390px 框。修复不改变 DSL、内容或模型调用，不覆盖冻结对照截图。

同源图表还修复了两处渲染缺陷：未指定文字颜色时不再传入覆盖 ECharts 默认轴配置的 `undefined`；笛卡尔图使用与框大小适配的图内边距。同一 138.5px 高的框内最高柱从 5.60px 恢复到 84.71px，两张对照图的类别标签均恢复。坐标、数据与冻结实验截图保持原样；另有 11 项应用图表测试通过。

## 质量验收限制

TTS 使用实际部署 `qwen-tts / qwen3-tts-flash / Ethan / speed 1`，18 段独立校准、30 段验收，均只合成一次。v4 使用独立校准集选定的相对误差加权，中文、英文及混合文本的合并总时长误差分别为 +3.02%、−3.13%、+2.52%；30 段预测合计 348.70 秒，实测 350.19 秒，总误差 +0.43%。符合用户新口径的固定文本汇总目标；逐段 ±10% 命中率仅作诊断，不再作为验收条件。

本实验检验固定讲稿的时长预测，尚不等于“目标时长→模型首次写稿→实际多段合成”的端到端验收。另行完成三语言、每组两页、阶段目标 120 秒的首次动作/音频实验：中文 134.17 秒（+11.81%），英文 118.89 秒（−0.93%），混合 106.65 秒（−11.13%）。仅英文组达到总量 ±10%；另外两组略超容差，因此不能宣称端到端时长目标已全面通过。中文稿量偏长与 TTS 预测偏差叠加，混合组主要是首次稿量不足；6 次动作响应、21 段实际音频均保留，没有按结果回炉、重新合成或调参。详见 [真实阶段验收](2026-09-14-teaching-stage-first-pass.md)。参数按供应商、模型、音色、语言、语速及计量版本精确匹配；混合文本明确英文参考词到中文等价单位的折算，未匹配配置使用标记的静态估计。详见 [TTS 实测及方法](2026-09-14-tts-first-pass.md)。

PPT 对照为八类构图各三页，每条件重复三次，216 个条件均已记录终态。生产 `deepseek-v4-flash` 配置不支持视觉，72 个草图条件不可测；另一次显式视觉模型探测返回 `Model not exist`，没有切换生产模型。其余 144 次生成尝试全部保留。按同一严格可见容器边界逐稿复核，固定提交基线首稿布局通过 37/72（51.4%），空间预算组 44/72（61.1%）；关键知识完整分别 45/72（62.5%）和 64/72（88.9%）。没有模型响应的样本计入尝试分母并单列，少量末行越出背景也判布局未通过，不代表每个失败均严重遮挡。95% 布局目标和全部关键知识保留尚未达到。基线最终出稿 24/72 与预算组 69/72 是链路出稿数量，不能代替质量率；基线不包含会话开始时工作区已有的未提交接受草稿修改。详见 [实验说明及完整统计](../research/first-pass-slide-benchmark.md)。
