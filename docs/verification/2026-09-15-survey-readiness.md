# 2026-09-15 上线前问卷链路验收

## 结论

生产服务已更新并恢复。40 个独立 Chromium 会话通过首页、课程、问卷填写、同时提交、刷新恢复和重复提交验收；同时读取教师统计成功。学生注册登录另通过同 IP 40 并发 HTTP 验收，以及完整浏览器注册、退出会话后重新登录验收。

本次验证通过生产 HTTPS / Nginx，测试客户端将域名解析到本机。结果覆盖本机部署处理能力，不代表所有学生终端、校园无线网络或公网延迟均已验证。

## 本次修复

1. 注册原先按共享 IP 限制 10 分钟 5 次；改为 IP 与规范化学号组合，保留同一账号失败尝试限制。
2. 教师问卷统计原先会因关键词配置或分析失败整体返回 503；现在仍返回已保存的原回答、人数和选择统计，词云明确标记不可用。
3. 网关的共享 IP 连接上限导致冷启动浏览器下载 JS/CSS 返回 503；静态构建资源与品牌资源不再消耗应用请求连接额度。同时将一般请求额度调整为 300 次/秒、突发 1200 次，容纳全班导航预加载。应用连接上限仍为 200。

第三项由首次真实浏览器压测重现：40 人中 32 人页面未能加载。Nginx 日志显示静态资源被连接限制拒绝；HTTP/2 将并发请求分别计为连接，空限流键不计入额度，见 [Nginx 官方文档](https://nginx.org/en/docs/http/ngx_http_limit_conn_module.html)。修复后的最终验收无浏览器异常、429 或 5xx 资源响应。

## 未完成的 OSS 历史版本核验

补充的 AccessKey ID 与当前备份账号相同。对两种 OSS endpoint 重新使用有效签名核验，普通对象列表返回 200，但版本配置和历史版本列表仍返回 403 AccessDenied。因此只能确认当前可访问的旧快照及未使用数据已删除，无法确认 OSS 是否启用了版本控制、是否另有非当前对象版本。

要完成这一项，需要管理员为该账号补充 `oss:GetBucketVersioning`、`oss:ListObjectVersions`、`oss:DeleteObjectVersion` 权限，或由管理员检查并清理备份前缀内对应的历史版本。权限证据：[OSS 版本访问结果](2026-09-15-oss-version-access.json)。文档和验收结果不包含访问密钥、学生姓名或原始回答。
