# 永久教材库与教材增强课程验收记录（2026-09-21）

## 交付范围

本次交付已把教材作为可长期复用的一等数据源接入课程生成链路，采用 PostgreSQL 关系模型、pgvector 1024 维向量、关键词检索和关系表图谱。课程保存不可变教材版本、章节范围、上游知识映射及依据快照，教学蓝图、课件和讲稿使用同一份快照。

主要落地点：

- 教材、版本、章节、原文块、概念、关系、案例、原图、检索项、向量配置、课程绑定及依据快照均落入关系表。
- 原始 Word 和教材图片继续使用现有文件资产存储；SHA-256 唯一约束和数据库任务锁用于去重。
- `.docx` 解析保留标题层级、编号、段落、列表、表格、图片关系、图题和稳定原文定位；目录条目不会进入正文知识抽取。
- 中文字符二元词元、英文数字词元和 PostgreSQL `simple` GIN 索引组成关键词召回；向量召回采用章节过滤后的精确余弦查询，RRF 参数为 60。
- 向量配置独立于聊天模型，默认 `text-embedding-v4`、1024 维；错误维度和非有限值会被拒绝。
- 教材课程图谱允许一对多、多对一和多对多映射，保留每个上游知识点的覆盖状态、目标节点和理由。
- 教材原图通过受保护的文件资产 ID 进入生成器，模型只接收服务端读取的图片字节，生成页面保存受保护 URL。
- 教师端新增教材库、教材详情和课程选书；学生投影会移除教材原文、证据、维护信息和未采用素材。
