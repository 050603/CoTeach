# V2 浏览器验收

2026-09-08 使用真实 Next.js 开发服务、Chromium 和独立 PostgreSQL 16.9 完成验收。设置、备课及师生各五阶段共 **12 个场景全部通过**。页面使用实际路由、认证、V2 数据读取和课堂动作，未模拟成功 API 响应。

## 复跑

```bash
OPENPBL_VERIFY_BROWSER=1 pnpm test:db:research
```

入口为 `scripts/verify-research-database.mjs`，创建独立容器、执行全迁移和业务持久化测试，然后调用 `scripts/verify-v2-pages.mjs`。需 Docker、已安装的 Playwright Chromium 及项目依赖。只复验设置和备课时可额外设置 `OPENPBL_VERIFICATION_PAGES=authoring`；默认覆盖全部场景。

浏览器脚本校验本地隔离数据库地址及数据库内随机标记，启动独立端口 3199 的 Next 服务；可通过 `OPENPBL_VERIFICATION_PORT` 选择 3199–3299。认证 Cookie 使用该次运行生成的随机签名密钥，不输出密钥。运行结束清理自己的服务、容器、上传目录、构建目录及 Next 自动添加的类型路径。

测试进程预加载隔离代码，屏蔽工作区 `.env*`、本地旧 AI 配置文件和外部 API key 环境变量，并阻止服务端 `fetch` 访问非回环地址。浏览器也阻止外部网络请求。该处理只作用于验收进程，不修改现用配置文件或现用数据库。

## 已验证行为

| 场景 | 实际断言 |
| --- | --- |
| 教师 AI 设置 | 显示“AI 服务设置”，provider-config API 成功，无“无法读取课堂数据”提示 |

| 学生五阶段 | 显示与教师一致的精确当前阶段，刷新后保持一致；第 3 阶段按产品流程进入 AI 协作文档工作台 |

五阶段为项目启动、知识讲授、项目实践、成果汇报与评价、学习反思。每个课堂场景同时检查真实 `/state` 返回的 `currentStageIndex`、主要内容容器及认证后 URL，收集本地 API 的 4xx/5xx 和未捕获浏览器异常。通过标准不使用泛化的“课程”“阶段”等文字，也不把加载过渡提示当成完成。

## 环境限制与重试记录

- 验收环境未配置外部模型。部分课堂页自动请求 AI 支持时返回明确的 **503 `AI_NOT_CONFIGURED`**，作为环境项单独记录。其余 4xx/5xx 均导致场景失败；未知 503 也不会自动放行。没有验证真实模型生成质量或远端服务可用性。
- 最终一轮中，设置页首次冷加载出现一次无有效堆栈的浏览器异常，新浏览器上下文重试后通过。
- 学生第 3 阶段首次等待 60 秒仍停留在进入协作工作台的过渡页面；重试后完成真实工作台加载、状态检查和刷新。
- 教师第 4 阶段一次 503 响应未成功读取 JSON 内容，被严格记录为失败；重试取得明确 `AI_NOT_CONFIGURED` 后通过。以上首次失败均保留于运行日志，每场景最多重试一次。

这次浏览器验收覆盖固定测试教案的页面读取、阶段切换和刷新，不代表所有编辑按钮、真实生成课件播放或外部 AI 功能均经浏览器实测。提交历史、并发入班、协作持久化、DOCX 归档、展示生命周期和研究导出由同一隔离数据库入口中的真实业务集成测试另行验证。
