# ADR 0013：采用区分先修与本课目标的课程知识结构

## Status

Accepted

## Context

当前 `knowledgePoints` 与 `knowledgeGraph.nodes` 被要求一一相等，`foundation` 同时承担“本课基础层”和“课前先修”两种含义，边关系主要依靠自由文本 `label`。这使系统无法稳定区分：

- 本节课准备从零讲授的基础概念；
- 学生在课程体系中此前理应掌握、缺失会阻断本课的知识；
- 仅能帮助理解、但不应占用课前诊断时间的背景知识。

高中自然语言处理课程暴露了这一问题：先前系统曾把分词、词性和分类的简化题当成前测，却没有识别人工智能三大基石、机器学习基本概念、数据特征与算法选择、数据集划分、监督学习过程及神经网络结构等课程体系中的前后衔接。

## Decision

- `CourseContent.knowledgePoints` 继续只保存本课负责教会和评价的知识目标。
- `KnowledgeGraph.nodes` 允许额外保存 `instructionalRole = prerequisite` 的课前先修节点；本课节点标记为 `lesson`。
- 本课节点声明可观察的掌握边界与所对应的学习目标；先修节点声明课程衔接证据与课前诊断边界。
- 图谱边使用结构化 `type`、`strength` 和 `rationale`。只有 `required-prerequisite + required` 的有向路径才可成为前测候选；`supports` 或 `helpful` 关系不得进入前测。
- 知识图谱生成必须先划定本课教学目标，再按学习者学段和完整知识阶梯逆向分析完成这些目标所不可缺少的课程体系前序知识。每门课至少保留 1 项真实先修，推荐 2-4 项、最多 5 项；不得生成零先修，也不得用常识题、低龄题、术语记忆题或本课预习题凑数。
- 个性化方案不再从本课 `foundation` 节点猜先修，而是直接消费已审校的先修节点和必需依赖路径。
- 每个被诊断的先修能力只生成一道高信息量前测题和一份独立 AI 补学资源；补学资源至少提供一个完整教学页面，并只服务该缺口。
- 旧图谱继续可读，但没有结构化先修证据时不会改变学生路径。

## Consequences

### 2026-08-12 补充：个性化阶段的反向复核

- 知识结构初次生成即使已经通过审核，也不能把“零先修”直接传给个性化路径。个性化生成必须结合最终主课页面，对每个本课目标再做一次独立的反向依赖分析。
- 年级、学习者画像或既往课程为空表示未知，不能作为零先修证据；“入门课”“通识课”“无需编程”也不能替代逐目标分析。
- 反向分析必须区分 `requires-prerequisite`、`covered-before-use` 和 `no-specific-prerequisite`。主课已覆盖只有在真实页面严格早于首次使用并完整讲授时才成立。
- 候选先修覆盖层需经过另一轮独立语义审核，审核通过后合并回统一知识图谱，再生成前测与一对一补学资源。快速生成和教师手动重生成都要持久化这份更新后的图谱。
- `required-prerequisite` 只允许从 `prerequisite` 节点指向 `lesson` 节点；本课目标之间只能使用支撑、应用、对比或迁移关系。

### 2026-08-12 补充：平台“知识启蒙”的语义

- CoTeach 的主要学习者是小学、初中和高中学生，也覆盖大学学习者。“知识启蒙”表示学习者仍在建立知识体系，不表示某个课程主题处于零基础层级。
- 课程入口分析采用“确定学段 → 定位本课目标在完整知识阶梯中的深度 → 反推必须的入口能力”的顺序。对 K12 学生而言，计算机视觉、自然语言处理等主题已经可能处于较深层级。
- “领域入门、通识、启蒙、无需编程”只能降低当堂课程的操作门槛，不能删除人工智能、数据、机器学习、特征等真实概念台阶。
- 年级或学习者画像缺失时使用“K12 学段待确认”的显式假设进行课程结构分析；它不是“无需先修”的证据。

### Positive

- 本课覆盖范围和课前应会范围具有明确边界。
- 知识图谱可以同时指导主课递进、前测选点、补学资源和达标测映射。
- “必需”与“有帮助”不再依赖模型对自由文本关系的猜测。
- 教师能够在备课页看见并审核前序课程衔接，而不是只看到本课节点。

### Negative

- 图谱 schema、规范化、质量门、编辑器和个性化生成需要同步升级。
- 知识图谱生成需要一次独立语义审校，模型调用和生成时间略有增加。

### Neutral

- 先修节点不是本课教学目标，不进入主课知识覆盖率和课后达标测统计。
- 旧课程需要重新生成知识结构和个性化方案，才能使用新的先修路径。

## Alternatives Considered

### 只增强前测提示词

拒绝。上游图谱仍无法表达课程体系前序知识，前测模型只能再次猜测并产生漂移。

### 为前测另建一张独立先修图谱

拒绝。两张图会重复维护节点与依赖，主课生成和个性化生成容易再次失去一致性。

### 把所有前序知识加入本课 `knowledgePoints`

拒绝。下游会把这些节点当成本课必须完整讲授和评价的目标，扩大课程边界并挤占主课时间。
