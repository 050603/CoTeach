# ADR 0018：讲稿语义驱动的细粒度视觉指引

## 状态

Accepted — 2026-09-16。

## 问题

固定 OpenMAIC 生成基线在同一次模型调用中交错生成动作和讲稿，这是应当保留的编排方式。原实现提供给模型的页面清单会截断文本，并把表格整体作为一个元素；无效的视觉目标还会被替换为页面首个元素。结果是动作虽然可播放，却可能指向错误内容。播放器只支持静止激光和整元素聚光，也无法在一个自然讲稿段中按讲解进度依次触发多个必要指引。

## 决策

CoTeach 直接扩展 OpenMAIC 原有的动作生成位置，不增加第二次模型编排。原有一次调用仍输出同一个动作与讲稿交错数组；扩展提示在该次调用中要求模型先判断指引必要性，再选择动作、目标、时间和路径。输入清单改为提供元素全文、实际可渲染的表格单元格、行列位置、合并关系和元素类型。

模型输出后只执行确定性的本地校准：验证目标证据和讲稿绑定，删除过渡或不可定位动作，合并同一目标，应用注意预算、间隔与 A-B-A 抑制。该步骤不调用模型、不改写或拆分讲稿，也不把“ID 存在”当成语义正确。校准失败时保留讲稿和非视觉活动，并取消未经验证的视觉指引。

编排先判断“不指引是否会让学生看错位置”，再决定是否绑定目标：

- 持续解释一个内容块、概念或表格单元格时使用 `spotlight`。
- 短暂指出术语、数值、流程节点或单元格细节时使用 `laser`。明确比较、列表或流程可让一次激光沿多个精确目标连续滑动。
- 过渡、标题复述、泛述、页面结构已经清晰、白板讲解或无法可靠定位时不添加视觉动作。

视觉注意力有明确预算：内容页最多八个焦点、最多两次激光，不设置最低动作数；不同目标原则上至少间隔十秒。相邻讲稿持续解释同一概念时合并为一个稳定的聚光区间，禁止为动作多样性切换工具，也禁止短时间 A-B-A 往返。表格多格和流程多节点优先作为稳定区域或一条连续激光路径处理；没有可靠共同区域时只选择最关键目标或不显示动作。

动作保留 `elementId`，并可增加 `speechId`、讲稿语义锚点 `speechAnchor`、校准后的触发时间 `speechOffsetMs`、聚光区间终点 `endSpeechId` 和细目标选择器。一个自然讲稿段可以绑定多个按时间依次触发的指引，没有“每段只能一个动作”的限制。表格单元格使用稳定的 `cellId`；单元格内部文字使用 `cellId + quote + occurrence`；其他文本片段使用 `quote + occurrence`。激光用 `waypoints` 表示最多四个后续目标，播放器在目标间连续滑动。运行时在当前画布内解析真实 DOM 区域，文本通过 `Range` 测量。细目标或路径中任一目标失效时取消整个指引，不回退到首个元素、整张表或表格中心。图片等没有结构化局部目标的对象只支持整体聚焦。

窗口持续到绑定讲稿区间结束。静止激光默认持续 2.5 秒；滑动激光按路径长度获得足够的展示时间；讲稿提前结束时同步清除。暂停隐藏当前指引并冻结讲稿内调度，恢复时还原仍有效的剩余状态；跳播到讲稿中部会恢复当时应显示的指引。换页、白板、视频、讨论、停止和播放结束都会清除指引。计时器使用动作令牌隔离，旧计时器不能清除新动作。同一时刻只显示一个视觉指引。

新课程生成和整页动作重生都复用 OpenMAIC 原有动作生成入口及相同的 CoTeach 提示扩展；实时授课工具共用相同的目标语义、滑动激光契约与动作分工。教师改绑元素时清除不再适用的单元格、文本选择器或路径。

## 与固定基线的差异

该扩展称为“语义必要性、注意预算与稳定焦点路径联合编排”。相对仓库记录的固定 OpenMAIC 基线，它在原有单次编排中联合处理可引用目标粒度、动作必要性、窗口与激光的语义选择、稳定焦点区间、连续激光路径和讲稿播放生命周期。契约扩展保持向后兼容，旧动作仍可按整元素和单段讲稿播放。

这是当前产品实现的工程差异。没有对照实验或学习效果数据时，不把它描述为已经证明的研究原创性，也不主张它已经提升学习效果。后续若用于论文，需要另行固定实验版本、基线、任务集、标注标准和学习结果指标。

## 验证要求

自动化测试覆盖新旧动作契约、讲稿区间与目标绑定、动作预算、目标切换间隔、合并单元格、单元格内文字、重复术语、跨富文本节点、失效目标、多画布隔离、暂停、区间内跳播、切页和计时器竞争。课程交付还需在真实授课画布与编辑预览中检查目标位置，并核对字幕、语音连续性和原讲稿完整性。
