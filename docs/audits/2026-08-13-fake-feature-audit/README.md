# 备课与课堂交互“假功能”审计

审计日期：2026-08-13

## 结论

本次审计确认并修复了两类对用户可见、但没有真实业务效果的交互：

1. 阶段架构中的资源选项。普通课堂阶段原先允许勾选“学习任务单、评价量表、项目任务书”等资源，但生成链路会无条件把这些阶段归一为教师演示页与讲稿，选项不会产生对应产物。
2. 阶段用途下拉框。阶段实际分流只由 `stageKey` 决定；下拉框写入的 `openMaicUse` 不会改变真实路由，且会制造可以人工改变阶段用途的错觉。

修复后，阶段架构不再显示资源选择、资源交付标题或默认生成说明。普通课堂资源和 AI 授知资源继续由固定生成链路处理。旧课程即使还保存了废弃选项，在生成请求、标准化和发布校验时也会被按真实阶段能力清洗。

## 审计范围与方法

- 静态扫描 `src/app` 与 `src/components` 中的按钮、链接、选择器、开关和空回调，共覆盖约 1,266 处交互声明。
- 从课程备课页追踪字段到标准化、课程请求、资源生成、发布校验与学生端消费位置。
- 在本地真实教师课程中复现“阶段架构”流程，对照修改前后页面。
- 对高风险候选逐项确认组件是否可达、控件是否明确禁用，以及是否存在真实消费者。

这是一轮代码与核心教师流程审计，不等同于完整 WCAG 合规审计，也没有遍历所有需要特定学生数据的运行时状态。

## 复核但未判定为线上假功能的候选

- `dashboard-shell.Toolbar`、通用 `ResourceList`、旧 `quiz-renderer` 和 OpenMAIC Agent 配置面板中的按钮目前没有被线上入口引用，属于未使用代码，不是用户可达的假按钮。本次不借机扩大删除范围。
- OpenMAIC 编辑器中的链接、自定义形状与画线 TODO 没有暴露为可点击入口；链接菜单已明确禁用，因此没有伪装成可用功能。
- 测验复核页的空 `onChange` 与禁用状态成对出现，用于只读答案展示，不是失效交互。
- 终局讨论卡片的拖拽空操作对应固定位置设计，不是用户承诺可拖动的控件。

## 验证

- 定向单元/组件测试：3 个测试文件、10 个测试全部通过。
- 涉及文件 ESLint：通过，无警告。
- 浏览器回归：阶段架构正常加载；普通阶段和 AI 授知阶段均无资源选择按钮、资源标题或默认说明。
- 全量 TypeScript 检查：命令运行超过 180 秒后超时，期间没有产生诊断输出；该项不能记为通过，需在资源空闲时单独重跑。
