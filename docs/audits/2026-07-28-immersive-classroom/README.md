# AI 伴学沉浸式课堂界面验收

验收日期：2026-07-28

## 验收原则

- 只读取当前本地系统与数据库状态。
- 不创建演示课程、演示学生、演示成果或其他假数据。
- 第 1、2 阶段固定使用传统学习页面；第 3–6 阶段的传统页面与 AI 伴学场景由教师配置。
- 当教师启用 AI 伴学场景时，任务、资料和过程记录作为场景内工作台展开。
- 教师端只呈现来自真实课堂状态的提醒、证据和评价。

## 实际界面路径

1. 首页：视觉层级与教师端、学生端入口可辨识。
2. 学生加入页：首次验收发现可交互表单被可选会话恢复的骨架屏阻塞。
3. 学生加入页（修复后）：页面加载后立即出现邀请码、姓名与“进入课堂”，不再等待可选会话恢复。
4. 教师端：未登录状态会进入教师登录页；未使用未知账号或伪造数据绕过鉴权。
5. 学生课堂与教师授课台：需要真实的已登录教师/已加入学生会话，当前浏览器没有该会话，因此本轮未对受保护页面作截图结论。

- 受保护课堂页的代码、类型、测试和数据规则已完成验证；视觉验收仍需真实登录会话。
