# 老师试用反馈模板

请每个问题单独填写一份；没有问题也可以写下最难找到或最难理解的一步。

| 项目 | 请填写 |
|---|---|
| 发生时间 | 日期及大致时刻： |
| 使用环境 | Windows/macOS、浏览器及版本、是否耳机或外接音箱： |
| 使用身份 | 教师 / 学生体验账号： |
| 所在页面 | 页面名称或地址；如在课件中，请写页码或阶段： |
| 操作步骤 | 1.  2.  3.  |
| 预期结果 | 我原本以为会发生： |
| 实际现象 | 实际发生了什么；错误提示的原文： |
| 是否能继续 | 可以继续 / 重试后可以 / 无法继续： |
| 截图或录屏 | 文件名或分享位置；如涉及学生信息，请先遮挡： |

声音问题请补充“是否静音、是否点击继续讲解、哪一页开始异常”；提交问题请补充“刷新或重新登录后记录是否还在”。
