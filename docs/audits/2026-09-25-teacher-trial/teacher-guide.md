# “测试课程”老师试用操作卡

**待交付草稿：新活动和新场次已开放，仍需完成学生现场完整听课、提交结果和实机验收；复验通过前请勿发送本卡。旧场次已归档，勿用旧链接。**

访问地址：`https://coteach.cn`。建议先在电脑 Chrome 或 Edge 中使用教师账号登录；另开一个无痕窗口或独立浏览器配置，使用学生体验账号登录。教师与学生不要共用同一浏览器登录状态。账号密码通过既定私密渠道提供，此卡不保存密码。

1. 教师进入“测试课程”，找到当前开放的“中小学人工智能教育的教学理论与方法”活动，进入课堂并查看授课状态、课件与在线学生。若已显示“授课中”，直接继续当前场次。
2. 学生从课程列表进入“测试课程”，打开同名活动，点击“进入课堂”。浏览器出现“继续讲解”时主动点击，并检查电脑未静音。第一次播放可能需要这次手动点击。
3. 学生依次查看课件、听讲、完成出现的测验；可暂停、继续、切换窗口后返回，并尝试刷新或退出重进。每次提交后确认页面反馈，再由教师查看对应学生记录。
4. 教师结束课堂后，双方重新进入查看保留的学习与参与记录。正式试用场次不要用于破坏性故障注入。

遇到问题请记录：页面地址、发生时间、操作步骤、预期、实际现象、浏览器和系统版本；能截屏时附上截图。声音或图片异常时，请注明对应页码。全课配音约 32 分钟，另有 8 组测验，建议预留完整体验时间。

可直接使用[试用反馈模板](feedback-template.md)记录问题。

本次试用只体验这门现成课程的授课、听课和随堂测验。实机验收完成前，本卡是待交付材料，不表示已可发送。
