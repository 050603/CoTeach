# CoTeach 教学图解视觉生成 v2

本次实现替换学生知识页的文字投影生成层，保留原生 `PPTElement[]`、编辑器、播放器和 PPTX 导出。原课程不因样板或基准执行而改变。协议版本为 `teaching-visual-v2`，规划为 `teaching-visual-planning-v3`，编译器及主题为 v3。

当前实施结果、样板入口、真实模型结果和未完成的产品验收见 [实施与验收记录](teaching-visuals-v2-acceptance.md)。

用户确认新版第 19 页样稿后，将其视觉规则接入真实生成的改动及保留失败见 [已确认样稿风格实现](teaching-visuals-approved-style.md)。

## 页面与构件

场景协议见 [teaching-visual.ts](../packages/@openmaic/dsl/src/teaching-visual.ts)。`TeachingVisualScene` 保存页焦点、构件、观察对象、真实关系、来源 ID、图片锚点和精确图表数据；坐标由编译器生成。构件支持状态变化、过程与决策、因果、结构、比较、图片标注、数据、推导演算，以及确需文字主导的解释。

| 内容 | 原生编译行为 |
| --- | --- |
| 状态变化 | 定性对象或学习者与支架；仅实际采用的变化成为箭头，不产生虚构坐标轴或百分比 |
| 过程与决策 | 保留原图完整节点、边、循环、分支和并行组；无原图时按声明关系布置对象，长链可采用连续两行 |
| 因果 | 原生关系线和就近条件；回路独立路由，不把并列项连成因果 |
| 结构 | 原生父子关系，层级布局与开放连接线 |
| 比较 | 原生矩阵按共同维度对齐；矩阵之外的条件与说明在同页保留 |
| 图片标注 | 原媒体保持独立图片，归一化锚点与原生文字、定位线叠加；不将文字烘焙进图片 |
| 数据 | 原生图表、原始类别与精确数值；单位单独测量，结论和适用条件贴近图表 |
| 推导演算 | 连续的可编辑步骤与引导线，结果突出显示，保留单位和必要条件 |

主题采用浅底、深色正文、蓝色结构线、青绿色状态和少量暖色；颜色仍需文字和形状辅助。16:9、1000 × 562.5 画布使用 Noto Sans SC，标题 32、核心标签 24、说明 20、必要图注和刻度最低 18。正文容量不足先换构图或拆页，不降低字体。

## 生成、来源和拆页

入口为 [teaching-visual-scene.ts](../src/lib/openmaic/generation/teaching-visual-scene.ts) 与 [teaching-visual-compiler.ts](../src/lib/openmaic/generation/teaching-visual-compiler.ts)。生产学生知识页使用新路径；视频、教师资源和旧协议保持各自入口。生成一次视觉场景，不增加布局比较或质量评审模型调用，保留既有生产模型和输出预算。

模型选择对象、构件和关系。程序使用播放器一致的真实字体测量，每页至多比较三个确定性构图，检验实际文字、媒体和构件是否完整可见。每个带来源的对象须实际进入画布；仅有来源 ID、透明播放别名或元数据不足以证明可见覆盖。原生图表与场景中的预期数据使用独立数组，编辑实际数值不会同步污染核对依据。

`visualSourceCatalog` 保留拆分页拥有的原始教学责任及稳定 ID。投影短标签不能回填 `newContent`；讲稿继续从原始采用资料独立生成。原图承接页保留图合同，兄弟页不承担重复的原图责任。所有允许新视觉拆页的页面先保存完整正文、展开页面，再依据工具合同生成连续讲稿或本页工具动作，避免白板页面丢失续页。小节总时长和知识归属保持守恒。

不可行时只进行一次有界局部重规划：重排完整注释、将完整图与既有条件分配到连续页，或拆分独立构件，不切断图拓扑。仍不可行保留既有可用稿，或编译完整原文首稿，并保存真实诊断。解析无效、不可执行输出和实际基础设施错误仍属于技术错误，不将其伪装成质量通过。

## 编辑、播放和恢复

`Slide.teachingVisual` 是可选元数据，旧页面无需迁移。它记录场景、构件与元素、来源、主题和编译版本。文字、关系、表格和图表保持原生可编辑，复杂图片是独立资产。

编辑器支持构件及整页换构图、锁定与解锁。元素移动、文字修改、图片替换、删除、新增对象和顺序调整会保存教师修改；删除 ID 作为墓碑保留。重排只处理未受保护的构件，同时保留媒体、图注、原播放目标与透明别名。异步重排期间出现新编辑时，旧结果不能提交。撤销/重做同时恢复画布和保护标记。整页重新生成不会静默覆盖已修改页面及其讲稿。

客户端换构图使用 `@openmaic/generation/browser` 的纯编译入口，未依赖服务器提示词加载器、Node 或 Playwright。真实浏览器打包回归同时覆盖编译、场景解析和来源核对的完整依赖链，不用 stub 或 external 隐藏运行依赖。

历史页面通过 `regenerate_scene` 的 `visualDesign` 入口进行指定页重设计。内容先实测、拆页，再直接从已采用教材生成本范围的连续讲稿。客户端在一次场景范围事务中提交原页及续页，原页保留 ID；撤销/重做同时恢复该范围的内容、讲稿、音频和大纲。提交前校验请求开始时的课堂、页面和版本，后来的教师修改不能被旧响应覆盖。

教师编辑器加载服务器保存的完整大纲，保存续页时保留其教学责任、来源归属与总时长。编辑接口授权后从实际课堂、规范大纲、已完成生成请求或同课程不可变模板恢复原始证据；不采用客户端填入的新教材。已发布课堂的编辑副本保存服务器生成的来源课堂身份，反复保存仍可追溯原来采用的教材。无法核对时保留当前页面、讲稿和音频，并返回实际诊断。

历史讲稿以原来的授课范围和已有音频速度作为参考。只有此前实际讲稿完整说过同一原始定义，才不要求本范围重新朗读；原文、定义引用及其他来源条目保持可用。只提过概念名、定义片段或计划中的知识不能证明已经讲过。讲稿估计时长与实际音频时长分别报告，保留目标秒数不能被当成音频时长已经验收。

局部重设计从小节中间页开始时，范围首页的交接合同保留 `continuation` 身份，并提供已经核对的完整实际前文；后续页面仍遵守相邻页面的闭世界合同。历史页讲稿按原音频速度校准估计；没有完整音频测量时使用默认估计。比较基准取原可用稿与计划时长中较长者，估计余量取 5 秒与原范围 10% 中较大值。新讲稿超过该范围时，返回真实诊断并保留原页、讲稿和音频。不额外调用模型、不裁掉必要事实、不加快语速。这个守护只能识别明显退化，不能证明新音频已经符合计划时长。

视觉设计、编译器、主题版本进入尚未完成的内容阶段指纹。已经完成且符合既有恢复合同的旧页面和阶段可以复用，避免升级触发整课重写。拆分页的内容、讲稿、动作仍走同一检查点合同。

## 隔离样板与可复现验证

第 19 页来自 `.openpbl-runtime/slide-redraw/single-pass-20261002/snapshot` 的冻结真实课堂资料。样板 A 表达支架渐退，样板 B 保留五个教学环节、独立探索的变化及两组评价信息。样板按 40 + 57 = 97 秒分配，未生成讲稿和音频，未修改原课堂。生产拆页根据实际可见教学负荷分配同一时长。

其余案例使用 [固定样板资料](../scripts/fixtures/first-pass-slide-samples.json) 及明确标注的基准示例；其中数据和代码绘制的独立 SVG 图片不是新增教材证据。来源表和逐页视觉观察单独保存，不能把基准示例称作教材原图。

```bash
# 输出必须是 .openpbl-runtime 下不存在的新目录；禁止覆盖已保存结果。
NODE_OPTIONS=--conditions=import pnpm exec tsx scripts/benchmark-teaching-visuals.ts \
  --mode=samples --output=.openpbl-runtime/teaching-visuals/新的样板目录

node scripts/render-teaching-visuals.mjs \
  --output=.openpbl-runtime/teaching-visuals/新的样板目录

# 实际部署模型：24 个案例各两次，另一次完整原第19页重设计，共49次。
# 只读获取部署路由和预算，禁止数据库写入、课程修改或音频生成。
NODE_OPTIONS=--conditions=import pnpm exec tsx scripts/benchmark-teaching-visuals.ts \
  --mode=model --deployment-secrets --concurrency=5 \
  --output=.openpbl-runtime/teaching-visuals/新的模型目录

# 固定实际响应的确定性重放，不追加模型请求，也不覆盖原失败结果。
NODE_OPTIONS=--conditions=import pnpm exec tsx scripts/replay-teaching-visuals.ts \
  --input=.openpbl-runtime/teaching-visuals/model-20261002-v2 \
  --output=.openpbl-runtime/teaching-visuals/新的重放目录

# 历史原第19页的完整来源、实际讲稿和周围页面联调，输出隔离副本。
NODE_OPTIONS=--conditions=import pnpm exec tsx scripts/verify-teaching-slide-redesign.ts \
  --model-input=.openpbl-runtime/teaching-visuals/model-20261002-v2 \
  --output=.openpbl-runtime/teaching-visuals/新的历史联调目录 --deployment-secrets
```

每次保存输入、原始模型响应、首稿场景、编译结果、采用结果、诊断、调用预算和实现指纹；原课堂前后指纹必须一致。每类三个固定案例覆盖中英文、长标签、精确数量、否定和数量边界、分支、回路及复杂图片。首稿、一次局部重规划、原文回退和技术失败分别统计，不以“任务完成”推导“内容和美观通过”。

渲染器使用实际 `ReadonlySlideCanvas`、生产 CSS 和字体；导出调用实际 `buildPptxBlob`，核对 ZIP、XML、文字、坐标、图片和原生图表数值。独立画布与常见视口检查不替代完整学生学习界面，也不等于已经在 PowerPoint/LibreOffice 打开并做视觉或编辑验收。完整学生界面检查使用浏览器隔离样板，拦截所有写入，报告其身份、课程绑定和数据替换范围。

最终隔离产物、逐页审查、真实模型和学生界面的结果在验收记录中分别说明。质量判断分为内容、视觉、编辑与播放、恢复与兼容、导出，教师对美术风格的认可仍是独立于结构检查的产品反馈。

## 相关检查

受影响的应用测试包括场景协议、真实字体编译、显示合同、拆页、来源、白板/动作与检查点恢复，以及编辑操作、保护删除、换构图和撤销/重做。DSL schema 测试覆盖新可选元数据和历史页面兼容；包内编译测试覆盖真实图拓扑与文字分配。

运行 `pnpm typecheck`、相关 Vitest 和修改文件的 ESLint。运行产物接通后按仓库约定执行 `pnpm build`，成功后 `systemctl --user restart openpbl.service`，验证 `http://127.0.0.1:3000/api/health/live`。构建或健康检查失败不能宣称页面已更新。

既有 `openmaic-baseline.test.ts` 中固定的旧 `slide-content/system.md` 哈希与当前仓库模板不匹配，本次没有修改旧模板或替换基准哈希；验证记录需单列这一既有失败。
